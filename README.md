## Features

- Email, phone, and supported social authentication
- Live post publishing with image uploads
- Feed, stories, likes, comments, saves, and sharing
- Creator profiles with editable profile information and links
- Premium responsive interface for web and Android

## Projects

- `InstagramClone.Api` — ASP.NET Core API and hosted web experience
- `InstagramClone.Mobile` — .NET MAUI Android application
